Boas práticas para uma web acessível

O mais importante para a acessibilidade é o código HTML semanticamente correto.

Títulos

Use um único h1 por página e siga a hierarquia, sem pular níveis. Leitores de tela permitem navegar pela tecla H.

Links

O texto do link deve fazer sentido fora do contexto. Evite “clique aqui” e “saiba mais”. Compare:

  • Ruim: Leia mais
  • Bom: O que é acessibilidade

Imagens

Imagens com conteúdo levam texto alternativo (atributo alt), de preferência com menos de 125 caracteres. Imagens decorativas usam alt vazio ou entram por CSS.

Contraste

A relação de contraste mínima recomendada é 4,5:1. Evite fundos decorados.

Multimídia

Vídeos precisam de legenda e transcrição, e não devem iniciar sozinhos.

Teste seu site

Use validadores como o ASES e leitores de tela como o NVDA. Teste também só com o teclado.
